# Green-API Telegram Messenger

Веб-мессенджер на **React + TypeScript** для отправки и получения текстовых
сообщений в Telegram через [Green-API](https://green-api.com/). Интерфейс
выполнен в стиле Telegram Web.

---

## 🚀 Быстрый старт

```bash
npm install
npm run dev
```

Откройте **http://localhost:5173**

---

## ⚙️ Как пользоваться

1. Получите `idInstance` и `apiTokenInstance` в
   [личном кабинете Green-API](https://console.green-api.com/).
2. Войдите в приложение, введя эти данные.
3. Введите номер телефона получателя (например, `79991234567`) —
   приложение автоматически определит его `chatId` через метод `checkAccount`.
4. Общайтесь: сообщения отправляются и приходят в реальном времени.

> ⚠️ Инстанс должен быть авторизован, а в его настройках должен быть
> **пустой `webhookUrl`** — иначе входящие не будут попадать в очередь.

---

## 🔌 Используемые методы Green-API

| Метод | Назначение |
|-------|------------|
| `checkAccount` | Получение `chatId` по номеру телефона |
| `sendMessage` | Отправка текстового сообщения |
| `receiveNotification` | Получение уведомления из очереди |
| `deleteNotification` | Удаление обработанного уведомления |

Документация: <https://green-api.com/v3/docs/>

## 🧠 Ключевая логика

- **Авторизация** — пользователь вводит `idInstance` и `apiTokenInstance`.
- **Создание чата** — по номеру телефона вызывается `checkAccount`,
  возвращающий настоящий `chatId` собеседника в Telegram.
- **Отправка** — `POST` на `sendMessage` с `chatId` и текстом.
- **Получение** — каждые **5 секунд** вызывается `receiveNotification`.
  После обработки уведомление **обязательно** удаляется через
  `deleteNotification`, иначе очередь «залипает» и новые сообщения
  не приходят.
